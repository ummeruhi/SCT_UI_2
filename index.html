Accessibility

How dark mode improves readability

The dark mode theme reduces glare and makes the app more comfortable to use in low-light conditions. It uses strong contrast between text and background, clear spacing, and readable font sizing to support accessibility. The light and dark theme toggle lets users choose the visual mode that feels most comfortable for them.

Accessibility features included

This design uses high-contrast text colors, readable paragraph spacing, larger headlines, touch-friendly buttons, clearly separated cards, and visible active states for navigation and filters. These choices make content easier to scan and read.
