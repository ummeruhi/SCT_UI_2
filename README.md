# 📰 Mobile News App with Dark Mode Toggle

A modern **mobile-style News App UI** built using **HTML, CSS, and JavaScript** as part of **SkillCraft Technology Internship - Task 02**.

This project demonstrates how to design a clean and accessible **news reading interface** with both **Light Mode** and **Dark Mode**, focusing on **readability, accessibility, and modern UI design**.

---

# 📌 Task Objective

The objective of this task was to design a **mobile news application interface** with:

- A **Dark Mode Toggle**
- Redesigned **main reading screens**
- Improved **readability**
- Better **accessibility contrast**
- High-fidelity **Light Mode** and **Dark Mode** designs

# 🔍 Functionalities Implemented

## 🌙 Dark Mode Toggle
Users can switch between light mode and dark mode using the toggle button.

## 💾 Theme Persistence
The selected theme is stored using **localStorage**, so the theme remains the same after refreshing the page.

## 🔍 Search
Users can search news articles by typing keywords in the search bar.

## 🏷️ Category Filtering
Users can filter articles by:

- All
- Technology
- Business
- Sports
- Health
- Science

## 🔖 Bookmark Feature
Users can save articles and view them later in the **Bookmarks section**.

## 📖 Article View
Each article opens into a **dedicated reading screen** with:

- Headline
- Author
- Date
- Image
- Article content

# ♿ Accessibility Improvements

This project focuses on improving **readability and accessibility**.

Key accessibility improvements include:

- High contrast text and background
- Comfortable spacing between content
- Clear heading hierarchy
- Large touch-friendly buttons
- Dark mode for reduced glare
- Clean card layout for easy scanning

These features make the app more **comfortable for reading news for long durations**.

---

# 🌙 Why Dark Mode Matters

Dark mode enhances the user experience by:

- Reducing screen glare
- Improving readability in low-light environments
- Reducing eye strain during long reading sessions
- Giving users control over their viewing preference
- Supporting accessibility standards
